# S3 — Three Pillars Section

**Component:** `src/AboutUs.svelte` — add after S2

## Layout
Three equal columns in a row, dark navy background.  
Each column: icon on top, bold title, short description below.  
Stacks to single column on mobile.

## Columns
| # | Icon | Title | Description |
|---|------|-------|-------------|
| 1 | `?` / person silhouette | **Why We Do It** | We want to bring stronger relationships between people by facilitating real connection |
| 2 | location pin / lightbulb | **Our Innovation** | We use AI to better moderate and keep our products clean by constantly using the cutting edge technology |
| 3 | group / people | **The Team** | Our team is dedicated to innovation and moderation in helping people make true connections |

## Notes
- Icons: use simple SVG inline or an icon font (e.g. a Unicode symbol is fine as a placeholder)
- Icon color: white or yellow `#facc15`
- Title: white, ~1.1rem, bold
- Description: muted white `rgba(255,255,255,0.65)`, ~0.95rem
- No borders or cards — just icon + text, centered
